# 星喵写作 1.0.0 使用指南

## 开始写作

安装时选择程序目录，例如D盘。程序位置和书库位置独立，书库可在设置中更换。升级前保存作品并备份；不要直接删除尚未核对的数据目录。两种版本使用独立书库，跨版本通过JSON备份与恢复迁移。

在书架新建作品，填写想法并选择短篇或长篇。短篇可从简纲拆章；长篇按全书大纲、分卷、卷纲/细纲、章节规划和正文逐步生成。结果先审核再采用，采用到对应目标后继续下一步。人工码字板提供独立草稿、目标、计时、查找和稿件历史。

## 资料与风格

人物、世界、关系、时间线、备忘录与规划分开维护。人物知情与读者已知须按生效章节处理；章纲和未来计划不能当作已发生事实。写作助手生成前检查本次引用资料，可选择仿写对标、风格、写作要求与Skill。仿写负责故事参考，风格负责表达，两组占比分开计算，0%项不进入请求；权重不是输出字数的精确比例。

金手指在“功能 → 金手指”按书保存，默认关闭。多人能力分别维护持有者、能力、限制、代价与成长计划；完整方案可粘贴Markdown或从本书备忘录导入。导入不代表启用，成长计划也不代表人物已获得能力。

备忘录支持分类、搜索、编辑与删除。人工灵感助手可引用所选资料，讨论不自动变成正文。知识蓝图和地点地图用于组织地点、人物、物品和引用；在地图中可维护层级、连线与位置，刷新及备份恢复保留关联。蓝图布局不改变已确认正文事实。

## 采用、定稿与保存

生成正文后先检查候选与实际引用，采用前程序会核对目标和资料变化。定稿时按需分析和核对资料同步，逐项确认有证据的变化；未确认内容不会自动成为有效事实。手写正文也可进入章节同步检查，避免重复记录。

正文自动保存，保存状态在工作区持续显示；写入失败会保留输入并阻止离开，可重试或按Ctrl+S。新建作品弹窗的未提交构思只保留在本次软件会话；关闭软件后的恢复不在此范围。

## 备份与恢复

JSON备份包含最终作品资料、章节和历史、风格/仿写档案及选择比例、Skill、蓝图、金手指、备忘录与回收站。恢复创建副本，不覆盖原书。密钥、账号会话、资料整理对话、方案撤销历史及过程性分析记录不包含在JSON备份中。请同时核对软件内备份说明，不把过程对话等同于最终作品数据。

## 两版区别与费用

开源核心版无需星喵账号，核心源码采用MIT。完整版增加账号、免费会员广场、创意工具箱、封面生成和内置更新，附加模块未开源。会员免费，只用于广场提示词库及权限管理；第三方模型和生图服务可能收费。

完整版工具箱可以分析生成内容、预览目标并核对后加入作品，按新书准备路线继续使用已保存资料。生图API未保存输入可在当前设置窗口内切换分类时保留，永久保存仍需点击保存。

**自动创作仍是预览功能。** 配置可以创建真实作品，之后可使用现有写作助手生成；运行页为计时演示。无人值守全书生成、真实后台批量调度、预算执行及崩溃续跑尚未实现。

## 发布与反馈

1.0.0安装包为Windows x64，尚未配置代码签名。两边GitHub首页默认英文，可切换简体中文，采用图标、简介、版本标签和一张真实界面图展示。问题反馈请附版本、复现步骤，去除密钥、账号会话和私人小说内容。
