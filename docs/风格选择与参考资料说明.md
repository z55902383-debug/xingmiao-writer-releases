# 风格选择与参考资料说明 · v0.6.9

## 从哪里选择

右侧写作助手的生成按钮上方常驻“风格与参考”，显示已经选择的风格和要求数量。点击后定位选择区与本次引用清单。助手中“选择写作风格与要求”也独立展示，可展开或收起，不再藏在参考资料总开关里。

## 多条资料怎么选

用“写作风格”和“写作要求”页签分别选择。前者决定视角、语言、对白和节奏，后者设置结构、段落和质量标准。页签数字表示选中数量；组内显示已选/总数。

已选条目排列在可选条目前，条目有完整名称和内容查看入口。本书旧档案有单独来源标签。搜索支持名称与来源文件名，“只看已选”用于核对现有选择。每类清空只影响当前类别。列表多时在列表内滚动，不会让所有内容无限堆叠。每类最多选择30条，没有填写或蒸馏生成内容的原文条目不可选择。

可以选择多条，也可以全部取消，用默认写法生成。选中后只发送条目内容，不发送未选资料或蒸馏原文。定向蒸馏只读取目标原文与补充要求，界面会明确提示：预设风格和要求用于后续创作。

## 核对当前引用与候选快照

“本次参考资料”按当前任务与设置核对，分成故事资料、写作依据和当前任务资料。只列出实际请求中的非空资料，展示已定稿前文、人物、世界、有效记忆、时间线、风格、要求和技巧等实际项目。未被发送的蒸馏原文、未来人物和未选条目不会被误报为已引用。预估字符数包含该次请求文本，不是计费金额或输出进度。

修改选择后显示正在核对；失败可点击“重新核对参考资料”。前文选择仍只读取已定稿的前章。候选稿顶部“这份结果实际参考”保存生成时的引用快照，修改当前设置不会改变旧候选；可展开查看当时使用的风格与要求。旧记录未保存完整清单时会如实提示。

## 其他入口

风格档案中央资料库支持搜索名称和来源文件名，也可按全部、已选用、待填写筛选。窄窗口点击“管理风格与要求”会关闭助手抽屉，展示资料页。目标字数直接显示在“参考范围与目标字数”旁，较低窗口或缩小设置区时仍保留参考入口和生成按钮。

完整资料编辑、导入、蒸馏、删除恢复见 [风格资料说明](风格与写作要求使用说明.md)。操作不会自动采用候选或覆盖正文。完整版会员免费，仅用于广场管理权限；第三方模型可能计费。安装与更新仍可选择目录。
