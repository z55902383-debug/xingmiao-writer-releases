# Skill 与提示词：广场、正常写作及工具箱联动

入口：设置 → 写作 Skill 管理统一库；普通写作助手 →「选择本次 Skill 与提示词」；创意工具箱 → 任意工具 →「风格与指令」。提示词有独立类型标记。

## 添加与默认选择

从广场添加的 Skill、提示词均注册为一份本地指令，默认启用。历史已添加但没有本地记录的条目会自动补齐；不会修改已有正文或覆盖人工停用的状态。设置中修改正文、任务、标签或启用状态后，已打开的选择面板自动刷新。

每个功能只展示适用条目。适用且已启用的条目默认全部勾选；不再保留工具箱10项、正文30项的选择上限。仅发送本次勾选的完整指令，不因条目多而静默丢弃尾部内容。

普通写作按「作品＋任务」分别记住开关；工具箱按具体工具分别记住。恢复默认启用会清除该范围的人工选择。取消选择现有条目，不会挡住以后新添加、启用的指令；切换任务、工具及重启会保留对应范围的人工选择。旧工具箱v1缓存按新要求重新以全局启用状态为默认。

全局启用状态决定默认勾选；在某个功能中也可以临时勾选全局未启用的适用条目，不会修改全局状态。

## 全部标签与对应功能

- 写正文、续写、润色、大纲、全书总纲、卷规划、卷大纲、卷细纲、本章规划、本章细纲、章节概要、世界设定、人物档案、提取记忆、连续性检查、分析风格、变化计划，分别对应现有17类写作任务。
- 封面、脑洞、书名、书名测试、简介、大纲、细纲、黄金开篇、金手指、名字、人设、世界观、词条、对标脑洞、对标书名、对标简介，分别对应16个工具箱专项。
- 黄金开篇专项可用于正常写正文、续写与润色；大纲专项联动全书和分卷规划；细纲专项联动卷细纲、章节规划、细纲与概要；人设专项联动人物档案；世界观专项联动世界设定。
- 普通写作任务标签也兼容匹配对应工具。明确的工具标签优先；封面、书名等不存在可靠对应关系的专项不会扩大到正文任务。
- 上传界面补齐卷规划、本章规划及本章细纲，支持多选章节任务和工具专项。导入导出保留任务、工具标签与自动/手动匹配模式。

只分析目标原文的风格蒸馏继续使用专属流程，不混入写作指令。记忆、规划等任务始终保留原有输出格式与事实校验约束。

## 取消、再次添加与删除

取消添加会让该条目从普通写作及工具箱同时消失，并暂停本地关联；再次添加恢复同一条记录、保留本地编辑及各功能开关，重新启用。重复添加不会重复注册。主动删除本地关联指令会同步标记广场未添加，避免下次查询自动重建；删除未添加的广场条目也会清理其暂停记录。

工具箱新建 Skill 或提示词默认启用、预选当前标签，进入统一库；有等价写作任务时一并可选。仅本次补充指令不会进入库。保存与读取期间不能开始生成，防止未读完便漏发指令。

后台按真实编号重新校验适用范围和内容，不接受客户端伪造正文。界面刷新后会清理已删除或不再适用的选择；携带陈旧编号直接调用生成接口仍会被拒绝。

## 当前版本

v0.6.12支持全部章节任务与专项工具标签。刷新或重新添加时同步已下载内容的来源标签，保留本地编辑、启用开关、自定义范围和编号；未添加内容不会自动安装。历史内容的专项标签已补全，无需逐条取消重加。
