# 创意工具箱：风格与指令

入口：创意工具箱 → 任一工具 → 展开「风格与指令」。封面生成器位于画风选择下方；文字工具位于创作信息下方。默认折叠，摘要显示已选数量。

- 可以多选带有当前工具专项标签的 Skill 和已添加的广场提示词，总计最多 10 项。只发送明确选中的内容，不沿用章节写作的全局启用状态。
- Skill 与提示词统一按专项标签筛选；同一内容可以标注多个工具，实现定向复用。列表支持搜索、查看完整内容、取消全选，已选条目优先展示。
- 「新建指令」可创建当前工具专用提示词，也可创建当前工具专项 Skill；自动带上当前工具标签，保存后选中。超过选择上限时只保存，并提示先取消其他选择。
- 提示词保存到创作广场，已经添加但不会隐式创建章节 Skill；可以从广场取消添加、删除。封面也已加入广场适用任务。
- 新建 Skill 保存在设置 → 写作 Skill，不附加章节任务且默认不启用。可在设置中修改内容、章节任务、工具箱专项标签，按工具标签或「未标注工具标签」筛选，导出或删除。工具箱选用不会改变全局启用状态。
- 「仅本次补充指令」用于临时语气、画风、禁用元素等，重新打开工具时清空，不进入指令库。
- 各工具的勾选项分别保存在当前设备，下次打开或重启后恢复。新增指令正文由现有本地库保存；切换工具不会串用勾选项。

封面指令直接合并进生图请求的 prompt，同时保留书名、基础画风、比例、构图与文字留白要求；文字工具保留专属任务格式和作品资料。Skill 仅作为文字指令，不执行脚本、安装依赖或调用其中描述的外部工具。多项要求矛盾时建议作者自行减少选择，模型不能保证每项风格要求都完全实现。

后端按编号重新读取本地库，不接受客户端伪造的已存指令正文。已删除的 Skill、取消添加或不适用的提示词会阻止请求，界面保留失效提示及移除入口，不悄悄改成默认生成。保存新指令期间生成按钮暂不可用，避免保存和生成并发导致漏用。

验证：`npm test`，`npm run build`，`npm run test:creative:ui`。桌面测试使用独立测试库与本地模拟文字/生图服务，验证实际请求内容、未选排除、新建保存、选择隔离与恢复、失效选择和设置返回、窄窗口布局，不消耗真实模型额度。

## 专项标签与广场分类

广场分类分为「章节写作」和「工具箱专项」两组，工具箱组包含与 16 个功能一一对应的分类：封面、脑洞、书名、书名测试、简介、大纲、细纲、黄金开篇、金手指、名字、人设、世界观、词条、对标脑洞、对标书名、对标简介。上传提示词和 Skill 均可多选专项标签；在具体专项分类下新建上传会预选该标签。上传文件存在 YAML 元数据时读取已有任务与工具标签，仍可在上传前调整。

Skill 的 `tasks` 仍只表示章节任务，独立 `toolTags` 数组存储工具编号。导入导出和作品备份恢复保留该数组。广场沿用现有 `tasks` 数组传输 `tool:cover` 等命名空间标签，避免新建的大纲生成器指令自动成为章节大纲规则。旧广场使用的工具编号继续兼容；关联旧 Skill 仅在尚无 `toolTags` 字段时继承广场标签，作者明确保存的空标签不会被自动填回。未标注旧 Skill 保留完整内容和启用状态，但不进入工具箱列表，作者可在设置中补标签。

后端库查询与生成入口都校验当前工具范围。旧选择因改标签而不再适用时，保留提示并阻止带着失效选择发出请求；可移除或补标签，不暗中扩大范围。

共享广场云端的标签白名单也已更新于 `supabase/functions/plaza/index.ts`。需要部署新的 `plaza` 云函数，线上上传才会接受 `tool:*` 新标签。本次完成本地代码和隔离模拟接口验证，未部署线上服务。原有广场内容仍兼容显示与添加。
