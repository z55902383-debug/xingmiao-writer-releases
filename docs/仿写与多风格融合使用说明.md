# 仿写与多风格融合

## 两个独立入口

- **仿写对标**：分析原作故事骨架、人物设定与关系、冲突转折、场景组织和行文，再用于构思本书的故事。
- **风格档案**：蒸馏句式、语言、节奏、视角和语感，剥离原作具体人物、剧情与世界观。写作要求仍单独选择。

每本书分别保存两套原文、档案、选择与占比。同一本书可同时使用故事对标A/B及文风C/D，两组各合计100%。新建作品无需选择创作或仿写。所有作品均可进入仿写对标：勾选对标即生效，取消全部勾选即停用，资料保留，文风不受影响。旧作品的模式字段不再作为启用条件。

## 上传、分析与采用

两页均支持多篇 UTF-8 TXT、Markdown，每批最多20篇；上传先核对，再保存。每篇分别分析并由用户核对候选后采用，待分析条目不可选择。仿写候选只更新对应故事对标，风格候选只更新对应文风，不覆盖正文。原文或档案已修改时拒绝采用陈旧分析。

过去上传的资料继续留在风格档案。仿写页「从现有风格原文复制」将原文复制为新的待分析对标，原风格不变，不自动转换或选用。可以手动填写故事对标档案，不必强制调用模型。

## 多选与融合

中央资料卡可直接勾选，也可点击上方标题标签选用或取消；助手展开仿写区后同样可选。底部「仿写、风格与参考」同时打开两套配置。中央保留大尺寸占比条，右侧助手提供同领域小尺寸占比条，两边拖动实时同步，松手或输入数字提交时保存。两个领域的滑块互不影响。

三篇对应两个分隔点，拖动只调整相邻两项。支持方向键1%、PageUp/PageDown 10%、Home/End；修改一个数字时其他项按原比例分配剩余值。单篇显示100%色带；0%保留选择但不进入模型。删除或清空档案会取消引用并重新分配，恢复不自动选用。配比操作不调用模型，也不修改已有正文。

## 模型输入与反馈

分析时只发送目标原文及作者补充，不混入另一领域档案或Skill。后续生成只发送已采用、已选且占比大于0的完整档案和独立权重，不附原文。

仿写用于总纲、人物世界、章节与时间线规划、正文及检查；文风负责语言表达，两组百分比独立计算。作者已确认的事实、设定、正文与章纲优先，润色保持原事件，记忆提取不注入故事对标。模型须根据权重综合参考，不能按比例截取原文、逐段拼接或仅改名字。

权重是模型的参考强弱，不能保证输出能精确测量为某个百分比。助手显示启用状态、实际引用与候选快照，可以查看当时完整对标档案和比例；之后修改配置不改变旧记录。未选用对标时不发送故事对标，不将旧文风冒充故事对标。

备份恢复保留两套资料、比例及作品方式。验证使用隔离数据和模拟模型，不代表真实模型的创作效果评价。

切换仿写对标与风格档案时，助手仅展示该领域的分析目标；无旧版单篇参考时自动选择有原文的风格条目。修改仿写选择或占比后，旧正文候选需重核，差异说明可查看对标变化。

仿写页的「仿写对标库」提供快捷标题标签、搜索及全部/已选用/待分析筛选；顶部「选择对标」清除筛选并定位资料库，待分析数量直达待处理资料。上传原文和新建档案分开摆放，保存后清除旧筛选，便于找到新条目。

原文区域的复制和数据说明入口统一为正常字号与点击高度；数据说明展开后独占一行，支持键盘开合。资料详情和原文入口扩大点击范围，更多菜单在滚动列表边缘自动调整展开方向，按 Escape 关闭并返回触发入口。
