# 关系记忆与旧文联动

入口有两处：

- 正文页 → 章名旁的“续写资料” → 续写状态与旧文检索 → 关系与原文联动。
- 功能 → 关系与记忆 → 事实记忆 → 每条记录的“关联旧文与变化”。

正文入口按当前章之前的已定稿来源整理；记忆入口允许浏览这条记录关联的全书已定稿历史，浏览本身不会改变生成引用。来源显示章节、版本、连续原文与原文位置，可打开对应章节。来源变化、未定稿、未来来源与证据不符的记录不参与正文索引。过期资料仍留在记忆板块，可编辑复核或重新提取。

## 本章按需引用

在正文入口勾选“仅引用本章相关关系记忆，固定设定始终保留”。为保留原有引用习惯，此选项默认关闭，按作品保存并随备份恢复。

开启后，根据章纲、摘要、写前卡、正文结尾、查询与生成补充要求匹配人物别名、物品和事件，再补充一层相关对象。它筛选的是历史事实记忆与已生效时间线；作者固定记忆始终保留。没有明确关联线索时回退完整引用并显示说明。可随时关闭恢复全量引用。最近10章完整正文不因此缩短，原始记录不删除。

这不是整份模型请求的总字数预算：人物档案、全书大纲、世界设定等仍保持原有规则。关联匹配是本地规则，不能保证识别全部隐含关系，引用前可查看计数与原文。

## 原文与历史

点击“查找相关旧文”会把对象带到旧文检索，关系记忆的原文证据会提高相关片段的推荐顺序。已完整引用的章节不重复发送片段；其他片段仍需明确勾选。关系索引和普通检索不调用模型，语义补搜仍需主动点击。

普通事实始终标记为历史，不能据此认定状态永久不变。明确归属维度（如保管人、持有人、所有者）按来源章节识别最近记录；同章不同持有人没有可靠交接顺序时标记待核对。有效时间线继续按其顺序计算当前状态。最近归属记录只是已记录信息，不代表已穷尽全书每次交接。

候选正文下方增加“与当前关系记忆核对”，只用本地规则提示明确的“某物在某人手中”与前文归属不一致，以及同章不同归属。排除明显引号、否定、假设、回忆和交接语句。这不是全文逻辑或语义审稿，可能漏报，也可能因合法交接而提示；不阻止采用、不自动改正文或记忆。

采用正文时保存实际关系来源依赖，后续来源变更继续进入改稿影响检查。

## 提取流程核查与修正

推荐流程为：生成候选正文 → 查看变化清单 → 采用正文 → 勾选核对的变化 → 确认同步并定稿。也可以采用并定稿后，在事实记忆页单独提取。

已检查和保留的校验：未采用候选不能同步；自动分析只生成清单，默认不勾选；同步校验正文哈希、版本与资料签名；入库来源必须定稿；证据必须为当前来源的逐字连续原文；整批原子提交，任一项错误全部回滚；禁止重复同步。

本次修正：

- 变化分析增加关键记忆类型，覆盖物品归属、明确承诺和关键事件，与人物变化共用核对清单，确认后写入事实记忆并保留来源。
- 分析上下文移除未来、计划和失效的时间线事件，以及未来人物和作者秘密字段。原先直接发送完整时间线，可能给提取带来干扰。
- 单独“从当前章提取”只提供当前正文，不再将章纲、全书规划、人物秘密等作为提取材料。提示明确区分承诺与兑现、回忆与当前状态。

原文包含证据只证明引用确实存在，不代表模型对句子的理解一定正确；特别是梦境、转述、隐瞒和反讽，仍需作者核对后勾选。

## 验证

新增8项关系索引测试与2项同步流程测试，覆盖历史交接、同章冲突、未来和过期资料排除、别名与证据检索、十章全文、仅正文提取、原子入库和备份选项。桌面验证覆盖两处入口、筛选开关、反查旧文、实际模型请求、关键记忆核对与入库。

合成检查构造200章约54万字符、2401条记忆；特定钥匙剧情可筛到1条相关记忆并保留10章完整正文。该结果只验证本地索引与组装逻辑，不能作为真实文学书稿检索质量、模型速度或费用保证。
