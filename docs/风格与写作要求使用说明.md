# 风格与写作要求使用说明 · v0.6.7

完整版和开源核心版都支持。进入作品 → 功能 → 风格档案，打开“写作资料库”。每部作品的资料独立保存。

## 自定义资料

切换“写作风格”或“写作要求”，点击新建，填写名称及内容。可创建多条：风格可以描述视角、句式、对白、节奏；要求可以描述结构、段落、避免表达及质量标准。保存后可编辑、删除、恢复和导出。最多100条，单条生成内容最多10万字符。

“导入风格或要求文件”支持 UTF-8 TXT、Markdown，或此功能导出的同类型 JSON。导入先放入编辑窗口，保存后才落库；取消不会创建条目。单条 JSON 导出包含名称、类型和生成内容，可导入其他作品复用，不包含蒸馏参考原文。

## 从文章蒸馏

在编辑窗口展开“从文章蒸馏”，粘贴或导入 UTF-8 TXT/Markdown 原文，点击“保存并蒸馏”。已经保存原文的条目可直接点击“AI 蒸馏”。使用当前已配置的模型，原文会发送至该模型服务；服务商可能收费，且有上下文与输出长度限制。

风格蒸馏分析视角、语言、对白、节奏与叙事方法；要求蒸馏提炼可执行约束，区分原文明确要求与分析建议。结果先显示在助手候选区，核对后点击“采用结果”才更新指定条目。不会改写小说正文，也不会自动采用。条目或原文在生成后被修改/删除时，旧结果不能直接覆盖，可复制后手动合并。

## 生成时选择

在右侧助手展开“本次参考资料”，找到“风格参考”。分别勾选写作风格和写作要求，支持多选或全部取消。只发送选中条目的生成内容，不发送未选条目或蒸馏原文。原本书风格默认沿用旧版行为，可取消勾选后改用新资料。

本次补充要求仍可临时填写，具体任务的输出格式和已确认事实优先。多个条目应避免互相冲突。候选结果中“本次使用的风格与要求”保存了生成时的内容，之后修改资料不会改变该记录。

## 编辑、删除和备份

编辑保留最近10次内容历史；载入旧版本后需要再次保存。删除会移入“已删除的风格与要求”，并立即取消生成引用；恢复后需重新勾选。原本书风格也可移除后作为自定义条目恢复。正文、参考文章与已有候选保留。

作品 JSON 备份包含自定义条目、原文、选择、历史和已删除资料。恢复创建独立作品副本，不覆盖原书。两个版本使用独立书库，迁移用作品 JSON 备份恢复。人工码字的独立临时稿与对话仍须另行存入作品或导出。

安装和更新可选择 D 盘等目录。旧安装若存在系统待重启删除任务，应先处理遗留任务或选用已核对没有相关任务的新目录。会员免费，仅用于广场提示词库管理与权限区分；第三方模型费用另计。
