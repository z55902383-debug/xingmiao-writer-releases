# 双列对照创作

## 章节页入口

章节标题右侧现在有“续写资料”“本章写前卡”和双列对照图标。前两个入口打开可关闭的侧边面板，不再把正文向下挤。续写资料中保留状态卡、旧文检索和关系联动。

点击“双列对照创作”进入：

- 左栏为AI参考稿，只读。首次优先选择当前候选或本章已有正文候选；也可以选择其他本章候选，或粘贴参考文。续写候选仅包含AI新增段落，会明确标注。
- 右栏为人工创作独立草稿，首次为空。输入自动保存，再次打开恢复已有内容。
- 参考稿以全文快照保存；其他位置重新生成或改变候选时不会自动替换左栏。切换参考不清空右栏。
- 拖动中间分隔线调整宽度，或聚焦分隔线用左右方向键调整。默认独立滚动，可以开启同步滚动。

进入对照时收起写作助手，给正文两栏留出宽度，助手仍可从原入口打开。常规正文整理和查找工具隐藏，避免对着草稿操作时改动原章节。右栏支持现有回车缩进设置。标题、正文和正式字数仍以原章节为准，直到写入人工稿。

## 保存与写入

对照输入保存到本地作品数据库，并随作品备份恢复。章节切换、退出对照或返回书架不会主动清空。额外保留浏览器本机恢复副本，以便恢复尚未完成数据库保存的输入；恢复副本不等于数据库备份，出现保存错误时应重试或导出。

“载入现有正文到右栏”仅在右栏为空时可用，防止覆盖正在创作的草稿。

“写入本章正文”才会更新正式章节，旧正文保留在历史版本中。写入后仍是草稿状态，作者需核对后定稿；左栏和未写入人工稿不成为正式记忆来源。记忆分析应针对写入后的正文重新进行。

如果章节已在其他入口改变，拒绝直接覆盖，保留人工稿并提示核对。可导出右栏，或用“另存为新章节并载入最新草稿”将输入保存为副本，不覆盖旧章。两个入口同时修改同一对照草稿时也会检查草稿版本，防止后保存的一方静默覆盖另一方。

## 人工码字板

在人工码字板选择同一本书的同一章节，再点击“双列对照创作”，会恢复同一份人工对照草稿和参考快照，Ctrl+S保存对照草稿。切回章节页可以继续写。

原人工码字板的普通本机草稿仍独立保留。若普通草稿也有尚未写入的内容，不会用对照稿静默覆盖；正常的章节冲突检查继续生效。独立临时稿尚未关联作品章节时，共享对照入口不可用，先选择作品章节即可使用。

## 验证

240项自动测试通过，新增对照保存、固定快照、版本冲突、历史恢复、备份重映射和冲突副本检查。桌面测试验证1464与1024像素宽度的双栏布局、两处入口共享、候选切换、显式写入、章节隔离和冲突恢复；原有人工码字、写前卡和续写检索流程也通过回归检查。
