# 版本提醒、回收站清理与步骤高亮

## 版本提醒

Windows 安装版启动后约8秒，会在更新服务器已配置且无正在进行的更新操作时静默检查一次。网络失败不会弹出打断写作的错误框，仍可在设置 → 版本与更新中手动检查。

发现新版本时，全局弹窗显示版本号和更新说明，支持下载、取消下载、稍后提醒和忽略此版本。“稍后提醒”为24小时后，关闭提示不自动安装。下载期间可关闭提示继续写作；下载完成后仍需用户主动点击安装。

安装前调用现有编辑器保存检查；保存失败保持软件打开。后台继续使用已有安装包校验、书库备份和安装流程，界面提示不能绕过后端校验。

更新后首次启动，会显示“版本更新完成”和当前版本说明，关闭后同一版本不重复。首次安装只建立版本基线，不显示虚假的更新成功提示；已有未关闭的升级说明会继续保留到确认。

开发版不自动检查或安装更新。本轮验证包括更新提醒状态及模拟更新事件的桌面操作，实际下载、校验和安装继续沿用已有更新模块；尚未重新打包安装版做端到端安装验证。

## 回收站保留周期

入口：设置 → 数据与回收站 → 回收站自动清理。

默认“不自动清理”，可选择7天、30天（推荐）或90天。改变选择后，需要点击“保存清理设置”才生效。

- 只处理设置回收站中的删除记录；归档作品长期保留。
- 首次启用或更改周期，现有条目获得新的完整保留期。同值重复保存不会延长保留期。
- 新删除条目按删除日期计时，显示剩余天数和到期日。
- 启动时检查，打开期间每小时检查一次；生成任务正在进行时暂缓。软件关闭期间不执行，到下一次启动再检查。
- 到期为永久删除。作品或章节对应的历史和候选一并移除；已导出的外部备份不受影响。
- 作品仍有较新、未到期的关联回收条目时，保留作品容器，等这些条目也获得完整保留期后再清理。
- 已恢复的活跃内容不会被旧回收记录删除。清理在数据库事务中完成，出错整批回滚。

人工码字板的普通本机临时稿和风格档案自带回收列表仍按原有规则管理，不属于设置回收站的自动清理范围。

## 步骤高亮

顶部“新手创作步骤”以及展开后的当前推荐步骤增加柔和流光。首次展示或当前步骤变化时播放一次，结束后保留静态高亮；其他步骤不持续闪动。当前步骤用可访问的step状态标注，悬停增强边框。

系统或浏览器设置为“减少动态效果”时关闭新增流光，保留静态颜色与文字区分。

## 检查结果

246项自动测试通过，覆盖保留期、永久清理、归档保护、恢复保护、关联条目期限、原子回滚和版本提醒持久化。桌面检查验证升级说明只显示一次、忽略指定版本、稍后提醒、清理设置保存、归档保留、步骤流光与减少动态效果，以及安装前保存与后端校验。
