# 资料整理助手使用说明

在右侧选择“资料整理”，输入想查询、梳理或调整的内容。读取当前作品的故事简介、总纲、分卷、人物、世界、关系、记忆、时间线和伏笔，不读取或修改章节正文、章纲、风格资料及备忘录。

建议不会直接写入。先核对清单，只勾选需要的项，再确认采纳。按真实记录显示写入数量与各项状态。剩余项不能沿用旧资料直接写入，可“重新核对未采纳项”生成新方案。

撤销须资料仍与采纳后状态一致，避免覆盖后续编辑。删除人物、世界卡、事实记忆、时间线及伏笔进入回收站；清空对话不清空回收站。

备份保存最终资料和回收站，不保存对话及方案撤销历史。恢复副本不能从旧对话撤销，但回收资料仍能恢复。模型请求可能计费，建议和证据需要作者核对。
