# 人工码字板使用说明 · v0.6.5

完整版与开源核心版均提供人工码字板。从书架左侧进入，可以独立写临时文稿，也可选择作品及章节载入原文。

## 保存与恢复

“草稿已保留在本机”表示独立的本机草稿；点击“存入作品”才会修改正式章节。临时稿存入作品时创建新章节。各章草稿独立保留，可返回继续写。临时稿管理支持搜索、重命名、删除确认与回收站恢复。

遇到作品章节被其他操作修改或删除时，旧草稿不能覆盖新内容。可另存新章节、导出 TXT，或保留副本后重新载入。重新载入、整理排版及载入生成稿前会保留副本。系统导出取消不算成功导出。

独立码字草稿、侧栏状态、灵感对话等保存在本机。普通作品 JSON 备份不是这些草稿和设置的完整备份；重要临时稿请先存入作品或导出 TXT，再迁移电脑或清理应用数据。两个版本使用独立书库，跨版本用作品 JSON 备份恢复。

## 编辑与专注

顶部按文稿、编辑、视图和专注分组。支持本章查找替换、撤销、段落排版、字体字号行距、专注计时与写作目标。F11 进入/退出专注，Esc 可退出。显示全文字数、本次净增与今日目标；载入旧稿不计为新增码字。

正文排版与主工作台共用规则。默认首行两个全角空格、段间空一行；保存设置影响后续输入与新生成内容，已有正文通过“整理当前正文”处理。普通 Enter 开始新段，Shift+Enter 普通换行；中文输入法确认不应触发换段。

## 稿件、灵感与备忘录

“稿件与历史”读取本章正文、生成候选和历史版本。载入或追加只改变码字草稿，存入作品前不会自动采用候选。

灵感助手和作品备忘录可从视图工具展开。助手需要你配置模型，仅参考明确选中的备忘录与输入；可选择整篇、指定标题/段落或多个原文片段。原文改变时需重新核对，不自动退回整篇。灵感回复可复制或另存备忘录，不自动写入正文。

宽窗口可同时显示两侧，窄窗口以最近使用的一侧为主。展开状态在本机保留。切换作品会区分对话与备忘录，不混用另一作品的参考。

## 安装与费用

两版安装时可选择 D 盘等目录。完整版内置更新继续提供安装目录选择；安装目录与书库目录独立。开源版下载 Setup.exe 手动更新。

**会员免费，无需付费开通。** 会员/普通用户只用于管理广场提示词库及区分权限。第三方模型、生图 API 可能另行收费。人工编辑、目标和计时不需要会员或模型；开源核心版不包含星喵账号、会员、广场、生图及内置更新模块。
