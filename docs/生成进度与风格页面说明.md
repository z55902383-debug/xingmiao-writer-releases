# 生成进度与风格页面说明 · v0.6.8

## 生成时的反馈

从卷章规划、风格蒸馏或写作助手点击生成后，助手顶部立即显示“正在准备资料”。请求发出后显示“等待模型响应”，收到文字后显示“正在生成内容”。正文完成后，如果正在核对人物、世界和记忆变化，会继续显示“正在分析故事变化”。状态位于助手滚动区之外，滚动结果或中央页面也能看见。

耗时和字符数来自当前任务，不使用假进度百分比。模型可能需要等待或暂停，等待时仍显示活动状态。生成中有柔和边框流光、流动细线和旋转图标；系统开启减少动态效果时使用静态提示。完成、停止、失败与中断都会结束动画。

点击“查看实时结果”定位当前任务，而非历史候选。流式文本默认显示最新段落；向上滚动阅读旧内容时暂停跟随，点击“跟随最新内容”恢复。既可在顶部停止当前任务，也可使用底部停止按钮。停止保留已收到的候选内容；停止故事变化分析保留已生成正文。内容仍需核对并采用，不会自动覆盖作品。

## 管理写作资料

作品 → 功能 → 风格档案，顶部“写作资料库”支持多条资料。写作风格决定语感（视角、句式、对白、节奏）；写作要求规定标准（结构、段落、禁用表达、检查）。每个页签下解释该类用途。

条目依次展示名称、可用状态、内容摘要和来源。“已选用”表示已在生成参考中勾选；“可选用”表示已保存内容但未勾选；“待蒸馏或填写”表示还没有用于生成的内容。编辑与有原文时的 AI 蒸馏直接展示。条目右侧“…”中的更多菜单提供导出和删除，删除仍需确认并可恢复。

下方“本书原有档案”是旧版的单份风格与参考文章，默认收起，概要显示是否已有内容。点击展开后可以继续导入文章、编辑本书风格或用 AI 分析写法。原有数据保留，也可在助手“本次参考资料 → 风格参考”中选择或取消。

风格与要求的完整操作见 [风格资料说明](风格与写作要求使用说明.md)。会员免费，仅用于完整版广场提示词库管理与权限区分。第三方模型服务可能计费。安装更新仍可选择目录。
