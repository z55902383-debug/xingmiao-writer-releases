# 分步创作与采用说明

v0.6.4 · 2026-10-06

按照“用户想法 → 全文大纲 → 分卷 → 卷大纲/细纲 → 章节大纲/细纲 → 每章正文 → 完成”推进。每一步都先生成、核对，再点击“采用结果”。采用后会提示下一步，不会自动启动下一次模型请求。

| 步骤 | 操作 | 采用后的对应位置 |
| --- | --- | --- |
| 用户想法 | 在故事基础信息中填写故事简介/想法 | 当前作品的简介 |
| 全文大纲 | 生成全书总纲 | 全文大纲；结果包含作品名时一并同步名称 |
| 分卷 | 生成分卷规划 | 创建对应分卷名称；已有卷按 ID 或同名匹配 |
| 卷大纲 | 在目标卷点击生成卷大纲 | 该卷名称及卷大纲 |
| 卷细纲 | 采用卷大纲后生成卷细纲 | 该卷细纲；若包含明确 chapters 结构，同时写入对应章名与规划 |
| 章节大纲 | 生成本卷章节规划 | 本卷章节名称、归卷和章节大纲（概要） |
| 章节细纲 | 补全本卷章节细纲，或逐章生成本章细纲 | 已有对应章节的名称与细纲 |
| 正文 | 对某章点击按细纲写正文 | 该章正文；如有资料变化，再审核同步清单 |
| 完成 | 核对每章内容并定稿，导出备份 | 全部计划章节都有正文并定稿后，步骤显示完成 |

## 核对与采用

候选区直接展示将创建或更新的卷、章及同步位置，无需自行复制到各字段。再次生成已有章节时，优先使用其真实 ID；没有 ID 时只在目标卷内匹配唯一同名章节。未列出的章节保留。规划只更新名称、概要与细纲，不覆盖已有正文；正文采用沿用原有替换/追加规则，并保留历史版本。

同名目标不明确、重复目标、跨书或跨卷 ID、结构不完整以及生成后被修改的规划，都不能直接采用；批量采用失败时整批回滚。给前卷补章时，新章会放在后卷前面，保留原有章节的位置。

旧版本的纯文字总纲、卷纲、卷细纲和单章规划仍可采用到原有目标。普通散文中的“第1–5章”这类章节范围不会被猜测成具体章节；要自动建章，请使用新版“生成本卷章节规划”。备份恢复后的旧结构化候选若包含旧 ID，请重新生成或复制整理，避免写错新书的目标。

## 界面

卷纲与卷细纲默认显示三行摘要，点击“查看完整内容”阅读全文；标题、列表和段落格式会整理显示。章节规划按需展开编辑，一次展开一章；可筛选分卷或搜索卷名/章名。采用后定位到对应卷或章。小窗口生成时会打开写作助手，采用规划后回到对应位置继续下一步。

## 费用与数据

会员免费，仅用于广场提示词库权限区分；开源核心版没有账号/会员/广场模块。第三方模型与生图 API 可能由服务商计费。请在模型设置中选择适合的输出长度，每卷章节数量也可通过补充创作要求指定。安装目录与书库目录独立；更换安装位置不会自动迁移作品。
