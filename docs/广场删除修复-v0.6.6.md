# 星喵写作完整版 v0.6.6 · 广场删除修复

- 修复“已添加到本机”导致共享内容删除按钮被禁用的问题。升级前已添加的内容和新上传的内容现在使用同一删除流程。
- 删除需确认，并由服务器验证当前账号是否为上传者；本机添加状态不参与权限判定。共享内容删除后保留本机副本，可继续使用或单独取消添加。
- 继续保留 v0.6.5 的人工码字、正文排版、灵感助手、备忘录片段引用及界面优化。

会员免费，只用于管理广场提示词库与区分权限；第三方模型/生图 API 费用另计。

## 下载

下载 XingmiaoWriter-0.6.6-x64-Setup.exe。安装及更新可选择 D 盘等目录，安装目录与书库独立。请先备份作品及重要临时稿。若旧目录已有系统待重启删除任务，应先处理遗留任务或选择已核对没有此类任务的新目录，再安装；这项广场修复不会清除系统删除队列。

开源核心版不包含广场，本次保持 [v0.6.5](https://github.com/z55902383-debug/xingmiao-writer-core/releases/tag/v0.6.5)。
