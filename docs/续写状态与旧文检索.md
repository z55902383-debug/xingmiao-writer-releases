# 续写状态与旧文检索

入口：进入作品正文页，点击章节标题右侧的“续写资料”，在侧边面板查看“续写状态与旧文检索”。它与安排本章必发生、禁发生和停笔点的“本章写前卡”分开。

新增“关系与原文联动”页签：查看关系与物品的历史、来源证据，并可启用本章相关记忆筛选。详细范围和记忆提取流程核查见[关系记忆与旧文联动](./关系记忆与旧文联动.md)。

## 续写状态卡

默认用于正文生成，可取消“生成正文时引用状态卡”。取消只移除这份状态索引，不删除人物、有效记忆等原有基础资料。

状态卡按照当前章的位置实时整理：

- 最近已定稿前章及其结尾承接；取消该章全文引用时，不由状态卡补发其结尾原文。
- 有效时间线中的人物、关系、世界及已记录故事时间。
- 带来源与原文证据的有效事实、物品和已记录承诺。承诺记录不自动等于尚未兑现。
- 人物、读者分别已知的内容，以及单列的作者秘密与揭露限制。
- 已在前文埋下的活跃伏笔。未来回收说明只作为作者提示。

每组最多显示12条来源记录，完整资料仍在人物、记忆和时间线中。未记录的时间、地点、物品或能力状态不猜测。固定约束与人工认知档案属于作者确认资料，不能冒充正文逐字证据。

修改来源章后，相关人物认知、作者秘密及伏笔会暂停引用，即使来源重新定稿也不自动恢复。状态卡列出待核对资料，可打开来源章节，核对后逐项重新确认；确认时会再次检查来源版本。旧事实记忆与时间线仍按原有过期规则处理，可在“素材与复核”重建。

## 检索旧文

默认保留最近10章完整正文；较早章节的片段作为额外补充。已有作品选择的其他完整引用范围继续生效。

在“检索旧文”页输入具体人物、物品或事件。也会结合当前章纲、写前卡和当前正文末尾查找。人物描述中明确标注的“外号、别名、化名、又名”等可参与关联，例如“老陈”关联“陈默”。

检索只使用当前章之前的已定稿正文，跳过草稿、未来章和已整章引用的内容。每个结果显示章节、来源版本、原文位置及本地匹配线索，正文直接切自来源。索引随正文、版本或章节顺序变化重建，不另存过期正文副本。

推荐片段默认不选中，勾选才发送；每次最多20段。调整完整前文数量或手动完整选章后，片段选择会清空，供作者重新核对。片段不会替代最近10章，也不会重复附加已完整引用的章节。

## 语义补搜

本地检索及状态卡不调用模型。点击“语义补搜”才调用当前配置的模型，会发送本次候选原文片段与查询，并产生相应调用费用或额度消耗，可停止。

每次最多比较64段候选，兼顾本地匹配结果及不同旧章的片段。它是有限候选范围内的语义推荐，不是整本书的穷尽语义检索，也未引入全库向量数据库。模型只能返回给定候选ID和理由，原文始终由程序从来源提供，不能用模型编造的引文替换。推荐理由仍需作者核对。

## 来源变化、候选与备份

来源修改、取消定稿、删除或改序后，旧片段不能继续用于生成，需清空选择并重新检索。模型补搜期间来源或当前章变化，也会拒绝迟到结果。

候选记录保存实际状态卡和已选片段的快照；修改当前设置不改写历史快照。采用正文后，片段和状态卡中的来源会计入改稿影响的引用依赖。

状态卡由已有资料重算，无需另存一份摘要；引用开关、确认状态和已采用正文的来源依赖随作品备份恢复。当前查询、未采用的临时勾选及本地内存索引不作为独立作品资料保存。

验证入口：`npm run test:continuity:ui`。
