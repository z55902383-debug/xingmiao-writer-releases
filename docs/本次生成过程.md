# 本次生成过程

入口：右侧写作助手的生成状态卡 → 本次生成过程。开始一次生成后即可查看，默认关闭，不增加正文顶部板块。

轻量版本展示四个阶段：

1. 整理参考资料：查看这次请求保存的引用清单，以及已有的风格、状态卡和旧文片段快照。后续编辑资料不会改变这份历史快照。
2. 请求模型与生成内容：查看阶段状态、首次正文响应时间、生成耗时及已接收字符数。取消、长度中断和错误分别显示真实状态。
3. 分析故事变化：显示进行中、完成、停止、失败、未启用或不适用；有变化时显示待核对数量，错误时保留说明。
4. 作者核对与采用：区分等待核对、结果已采用，以及正文已采用但变化尚待核对。过程展示本身不写入正文、不确认记忆。

新任务保存请求开始、首次正文输出、生成结束和分析阶段时间，进程结束后耗时不再持续增长。旧任务缺少时间时，详情标记“耗时未记录”。已有记录继续可用，不补造历史时间。

此版借鉴任务状态与详情查看的交互思路，以本项目现有任务数据独立实现，没有加入蜘蛛动画、MCP服务、分流评分或时间轴回放；打开面板不会增加模型调用。新时间字段随候选记录保存并在备份恢复时保留。

验证：246项自动测试及生成交互桌面检查通过，覆盖引用快照、等待与输出、非正文任务不适用分析、完成、分析中及停止保留正文，检查桌面和较窄窗口显示。
